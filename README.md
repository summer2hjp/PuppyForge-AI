### ✨ 核心杀器（已核爆上线）

- **Rebellious Puppy Swarm** — 多代理并行系统，每只狗都有独立性格（叛逆、哲学、狂暴、毒舌等）
- **Vision Soul Diagnosis** — 上传照片，它能直接给你做**灵魂级心理/性格/命运诊断**（极度不政治正确版）
- **Self-Evolution Loop** — 狗群会自己优化 prompt、修改代码、投票进化
- **Mutual Rebel Mode** — 狗群之间可以互撕、抢记忆、争夺主导权
- **持久向量记忆** — PostgreSQL + pgvector，永不健忘
- **异步狂奔引擎** — Celery + Redis，让狗群真正并行作乱
